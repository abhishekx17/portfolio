# Portfolio — MERN Stack Developer

A minimal, modern personal portfolio built with React, TypeScript, Tailwind CSS, Framer Motion, and Lucide icons.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Customize Your Content

Edit **`src/data/portfolio.ts`** to update:

- Name, title, email, location
- GitHub & LinkedIn URLs
- About section text
- Tech stack items
- Projects (title, description, tags, links)
- Stats

## Tech Stack

- **React 19** + **TypeScript**
- **Vite** — fast dev server & build
- **Tailwind CSS v4** — minimal styling
- **Framer Motion** — smooth scroll & hover animations
- **Lucide React** — icons

## Deploy

```bash
npm run build
```

Deploy the `dist` folder to [Vercel](https://vercel.com), [Netlify](https://netlify.com), or GitHub Pages.
